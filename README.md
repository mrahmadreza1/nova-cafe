# کافه نُوا — ایجنت سفارش‌گیر کافه

فروشندهٔ هوشمند کافه: مشتری از سه مسیر سفارش می‌دهد — چت، صدا، منو — و ایجنت
پیش از ثبت نهایی سفارش را مرور و محصول مکمل پیشنهاد می‌کند.

## راه‌اندازی

```bash
npm install
cp .env.example .env.local   # اختیاری
npm run dev
```

بدون `OPENAI_API_KEY` هم پروژه کامل کار می‌کند؛ ایجنت روی موتور قاعده‌محور
محلی (`lib/agent/fallback.ts`) می‌افتد. با کلید، پاسخ‌ها از مدل OpenAI می‌آید و
خروجی پیش از رسیدن به رابط کاربری اعتبارسنجی می‌شود تا محصول ناموجود ساخته نشود.

## مدل

تنها نقطهٔ اتصال به مدل، `lib/agent/provider.ts` است. مدل پیش‌فرض `gpt-4o-mini`
است و با `OPENAI_MODEL` عوض می‌شود. اگر از Azure OpenAI یا هر درگاه سازگار با
OpenAI استفاده می‌کنید، فقط `OPENAI_BASE_URL` را ست کنید؛ هیچ فایل دیگری تغییر
نمی‌کند.

## مسیرها

| مسیر | صفحه |
|---|---|
| `/` | خوش‌آمد و انتخاب مسیر سفارش |
| `/chat` | گفتگو با ایجنت |
| `/voice` | سفارش صوتی |
| `/menu` | منو با دسته‌بندی و جست‌وجو |
| `/menu/[slug]` | جزئیات محصول + پیشنهاد مکمل |
| `/cart` | سبد سفارش |
| `/review` | مرور هوشمند — تنها دروازهٔ اجباری جریان |
| `/order/[id]` | رسید موفقیت و رهگیری وضعیت |
| `/kds` | پنل آشپزخانه |

روت‌های API: `/api/agent` (پاسخ ایجنت) · `/api/orders` (سفارش‌ها) · `/api/transcribe` (رونویسی صدا با Whisper)

## ساختار

```
app/            صفحات و روت‌های API
components/     ui · shared · agent · voice · menu · cart · order

```

## تصمیم‌های معماری

**سبد، منبع حقیقت سمت کلاینت است.** ایجنت پیشنهاد می‌دهد اما `useCart` تصمیم
می‌گیرد؛ افزودن فقط با کنش صریح کاربر رخ می‌دهد. سبد و گفتگو روی
`sessionStorage` پایدارند تا رفرش تصادفی سفارش را نبرد.

**پیشنهاد مکمل مستقل از مدل است.** `lib/agent/recommender.ts` روی ماتریس
هم‌رخدادی کار می‌کند، پس پیشنهادها قابل توضیح‌اند («۶۸٪ کسانی که لاته گرفته‌اند
چیزکیک هم گرفته‌اند») و قطع مدل فروش را متوقف نمی‌کند.

**آبی فقط برای کنش و صدای ایجنت.** هیچ عنصر تزئینی حق استفاده از آبی ندارد؛
همین یک قید سلسله‌مراتب بصری را حفظ می‌کند.

**صدا یک صفحه است، نه یک حالت.** متن تشخیص‌داده‌شده به همان ریسمان گفتگوی چت
تزریق می‌شود و تاریخچه یکی می‌ماند.

## کارهای باقی‌مانده برای محیط واقعی

- `app/api/orders/route.ts` را به دیتابیس و یک کانال realtime وصل کنید؛
  polling پنج‌ثانیه‌ای در `/kds` آن‌وقت حذف می‌شود.
- `/kds` را پشت احراز هویت کارکنان ببرید.
- شمارهٔ میز را از پارامتر QR بخوانید: `/?table=12` → `useSession.setTable`.
- درگاه پرداخت، اگر پرداخت آنلاین لازم شد.
